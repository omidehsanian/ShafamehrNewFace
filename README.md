# سامانه مدیریت متمرکز بیماران — نسخه وب‌محور (طراحی جدید)

Install Python
Install SQL Lite
## نصب و اجرا (برای توسعه/تست)

```

pip install -r requirements.txt
python main_web.py
```

## ساخت exe

روی ویندوز، `build.bat` را اجرا کنید (فایل‌های `web/` و `backend/` به‌طور
خودکار داخل exe بسته‌بندی می‌شوند).
