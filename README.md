# سامانه مدیریت کلینیک فیزیوتراپی — نسخه وب‌محور (طراحی جدید)

نسخه جدید با رابط کاربری کاملاً بازطراحی‌شده: به‌جای Tkinter، از HTML/CSS/JS
واقعی استفاده می‌کند (نمایش‌داده‌شده در یک پنجره دسکتاپ بومی با `pywebview`،
که روی ویندوز از موتور Chromium/WebView2 استفاده می‌کند). این یعنی:

- راست‌به‌چپ واقعی و بدون باگ (مرورگرها ذاتاً bidi را درست مدیریت می‌کنند)
- کپی/پیست، نشانگر تایپ، فونت فارسی — همه به‌صورت طبیعی و بدون دردسرهای Tkinter
- ظاهر مدرن: کارت‌ها با سایه ملایم، گوشه‌های گرد، رنگ‌بندی هماهنگ با روانشناسی
  رنگ محیط درمانی (آبی/فیروزه‌ای = اعتماد و آرامش، سبز = بهبود)
- تقویم شمسی سفارشی (بدون کتابخانه جانبی)، دقیقاً همان الگوریتم نسخه قبلی

## ✅ وضعیت فعلی: همه بخش‌ها کامل و وصل به دیتابیس واقعی هستند

- صفحه ورود + فعال‌سازی لایسنس منقضی + قفل خودکار
- **بیماران**: لیست، جستجوی زنده، فرم کامل، افزودن/ویرایش/حذف
- **نوبت‌دهی**: ثبت نوبت، ظرفیت روزانه با هشدار، تغییر وضعیت، حذف
- **کتابخانه تمرینات**: افزودن تمرین، تخصیص به بیمار
- **پیگیری پیشرفت**: ثبت وضعیت + نمودار خطی روند (SVG داخلی، بدون کتابخانه جانبی)
- **گزارش‌ها**: خروجی اکسل بیماران/نوبت‌ها/پرونده تکی، ایمپورت دسته‌ای بیماران، پشتیبان‌گیری
- **کاربران**: تعریف کاربر جدید با نقش (فقط مدیر)
- **لایسنس**: نمایش وضعیت + فعال‌سازی با کد (فقط مدیر)
- **تنظیمات**: نام برنامه، لوگو، ظرفیت روزانه، مدت قفل خودکار (فقط مدیر)

هر صفحه با پیش‌نمایش تصویری (رندر واقعی HTML/CSS) بررسی و رنگ‌ها/چیدمان تأیید شده‌اند.

## 🔐 امنیت سیستم لایسنس (به‌روزرسانی مهم)

سیستم لایسنس از **رمزنگاری نامتقارن (Ed25519)** استفاده می‌کند، نه یک کلید
مخفی ساده:

- کلید عمومی داخل `backend/license_manager.py` است و همراه برنامه/exe توزیع
  می‌شود — فقط می‌تواند اعتبار لایسنس را **بررسی** کند.
- کلید خصوصی فقط در `PRIVATE_DO_NOT_SHARE/license_private_key.pem` است —
  فقط همین فایل می‌تواند لایسنس **بسازد**.

این یعنی حتی اگر کل پوشه `backend/` و `web/` (یعنی تمام کد برنامه) را به یک
توسعه‌دهنده یا شریک بدهید، او **نمی‌تواند** لایسنس معتبر جدید بسازد — چون
کلید خصوصی را ندارد و از روی کلید عمومی هم قابل استخراج نیست. فقط کافیست
هنگام اشتراک‌گذاری کد، پوشه `PRIVATE_DO_NOT_SHARE/` را کنار نگذارید (توضیح
کامل در `PRIVATE_DO_NOT_SHARE/README.md`).

⚠️ محدودیت واقعی: این روش جلوی **ساخت لایسنس جعلی** را می‌گیرد، اما اگر کسی
کد کامل را داشته باشد، همچنان از نظر فنی می‌تواند خودِ چک لایسنس را از کد
حذف کند و نسخه‌ی تغییریافته بسازد. جلوگیری از این مورد یک مسئله‌ی حقوقی/قراردادی
است (قرارداد همکاری، NDA)، نه چیزی که با کد قابل حل باشد.

## نصب و اجرا (برای توسعه/تست)

```
pip install -r requirements.txt
python main_web.py
```

## ساخت exe

روی ویندوز، `build.bat` را اجرا کنید (فایل‌های `web/` و `backend/` به‌طور
خودکار داخل exe بسته‌بندی می‌شوند).

## نکته فونت

فعلاً از فونت سیستم (Tahoma/Segoe UI) استفاده می‌شود که فارسی را خوب نشان
می‌دهد. برای ظاهر حرفه‌ای‌تر می‌توانید بعداً فونت **Vazirmatn** (رایگان،
طراحی‌شده مخصوص رابط کاربری فارسی) را به `web/css/` اضافه کنید — من به دلیل
نبود دسترسی اینترنت در محیط توسعه نتوانستم فایل فونت را از قبل بارگذاری کنم.
